# Проект my_course_report

## Описание:

Проект my_course_report - это тестовое банковское приложение для работы с транзакциями.

## Установка:

1. Клонируйте репозиторий:
    ```
    https://github.com/ViktorPilot/masks-date.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Зависимости установятся автоматически при открытии скачанного репозитория.
5. Программа готова к работе.

## Запуск проекта через главный модуль main.py:

1. В Python файле `main.py` необходимо запустить выполнение программы командой `poetry run python main.py`.
2. Далее после запросов программы ввести значения для фильтрации операций по типу исполняемого файла, по статусам
   транзакций, по возрастанию/убыванию дат транзакций или пропуска данной фильтрации, по выводу всех транзакций или
   только рублевых, по выбору транзакций с использованием определенному слова в описании или без него.
3. В результате получим список транзакций, соответствующий заданной фильтрации.

## Использование отдельных модулей:

### Для модуля widget.py:

1. В Python файле `widget.py` необходимо ввести номер счета (карты) `card_info`  в формате
   `"Счет 64686473678894779589"`,
   а также дату `date` в формате `"2024-03-11T02:26:18.671407"`.
2. Запустить выполнение программы командой `python -m src.widget`.
3. В результате получим зашифрованный номер счета `Счет **9589` и дату в формате `11.03.2024`.

## Тестирование:

Данный проект покрыт юнит-тестами с использованием фреймворка pytest.
Для их запуска выполните команду `poetry run pytest` из корневой директории проекта.

### Реализованы:

### Для модуля main.py:

+ Тестирование работы приложения при чтении транзакций из xlsx-файла при стандартных условиях.
+ Тестирование работы приложения при чтении транзакций из csv-файла при стандартных условиях.
+ Тестирование работы приложения при чтении транзакций из json-файла при стандартных условиях.
+ Тестирование работы приложения при отсутствии транзакций по выбранным статусам.
+ Тестирование работы приложения при первом неверном вводе статусов.
