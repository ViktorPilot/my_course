# Проект my_course_report

## Описание:

Проект my_course_report - это тестовое банковское приложение для работы с транзакциями.

## Установка:

1. Клонируйте репозиторий:
    ```
    https://github.com/ViktorPilot/my_course.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Создайте виртуальное окружение командой `poetry install`.
5. Активируйте ВО командой `poetry env activate`.
6. Установите зависимости командой `poetry init`.
7. Программа готова к работе.

## Запуск проекта через главный модуль main.py:

1. В Python файле `main.py` необходимо запустить выполнение программы командой `poetry run python main.py`.
2. Далее после запросов программы ввести:
   + значение даты на которую необходимо получить данные по транзакциям 
   за указанный месяц в формате `2020-03-15 10:50:03`.
   + значение даты на которую необходимо получить средние траты в каждый из дней недели за последние три месяца
   в формате `2020-03-15 10:50:03`.
   + путь до файла с транзакциями (по умолчанию установлен: `"data/operations.xlsx"`).
3. В итоге получим данные по результатам работы всех модулей пакета `src`. Подробное описание выходных значений 
   изложено ниже в разделе `Использование отдельных модулей`. 

## Использование отдельных модулей:

### Для модуля views.py:

1. В Python файле `views.py` необходимо ввести дату на которую необходимо получить данные по проведенным транзакциям
   (сумму всех расходов, кэшбэка по каждой карте за период с начала месяца) в формате `"2020-03-15 10:50:03"`.
2. Запустить выполнение программы командой `python -m src.views`.
3. В результате получим json файл с данными (приветствие в зависимости от текущего времени;
   по каждой карте: последние 4 цифры карты, общую сумму расходов, кешбэк; топ-5 транзакций по сумме платежа, курс
   валют, стоимость акций из S&P500.) в формате:```{
    "greeting": "Доброе утро",
    "cards": [{"last_digits": "4556", "total_spent": 8541.02, "cashback": 85.41},
        {"last_digits": "7197", "total_spent": 3158.03, "cashback": 31.58}],
    "top_transactions": [{"date": "16.01.2020", "amount": 3100.0, "category": "Пополнения",
                        "description": "Внесение наличных через банкомат Тинькофф"},
        {"date": "16.01.2020", "amount": 2130.0, "category": "Пополнения", "description": "Перевод с карты"},
        {"date": "15.01.2020", "amount": -2127.32, "category": "Другое", "description": "ГУП ВЦКП ЖХ"},
        {"date": "19.01.2020", "amount": 2100.0, "category": "Пополнения", "description": "Перевод с карты"},
        {"date": "17.01.2020", "amount": -2100.0, "category": "Переводы", "description": "Перевод на карту"}],
    "currency_rates": [{"currency": "USD", "rate": 77.28}, {"currency": "EUR", "rate": 91.66}],
    "stock_prices": [{"stock": "AAPL", "price": 19765.85}, {"stock": "AMZN", "price": 15361.84}]
    }```.

### Для модуля utils.py:

1. В Python файле `utils.py` необходимо ввести дату на которую необходимо получить данные по проведенным транзакциям
   (сумму всех расходов, кэшбэка по каждой карте за период с начала месяца) в формате `"2020-03-15 10:50:03"`,
   путь до файла с транзакциями в формате `"../data/operations.xlsx"`, путь до отдельного файла пользовательских
   настроек в формате `"../user_settings.json"`, тип валюты, конвертацию которой мы хотим произвести в формате `"RUB"` 
   и тип валюты, в которую мы хотим перевести.
2. Запустить выполнение программы командой `python -m src.utils`.
3. В результате получим:
   + приветствие в зависимости от текущего времени в формате:
   `«Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи»`.
   + по каждой карте: последние 4 цифры карты, общую сумму расходов, кешбэк за период с начала месяца по текущую дату в
   формате: `[{'last_digits': '4556', 'total_spent': 362.0, 'cashback': 3.62}]`.
   + топ-5 транзакций по сумме платежа за период с начала месяца по текущую дату в формате:
   `[{'date': '04.01.2020', 'amount': -362.0, 'category': 'Красота', 'description': 'OOO Balid'}]`.
   + курс валют на текущее время: `[{'currency': 'USD', 'rate': 77.26}]`.
   + стоимость акций из S&P500 на текущее время: `[{'stock': 'AAPL', 'price': 19762.51}]`.

### Для модуля services.py:

1. В Python файле `services.py` необходимо ввести список словарей транзакций в формате: ```[{
            "Дата операции": "01.01.2018 20:27:51",
            "Дата платежа": "04.01.2018",
            "Номер карты": "*7197",
            "Статус": "OK",
            "Сумма операции": -316.0,
            "Валюта операции": "RUB",
            "Сумма платежа": -316.0,
            "Валюта платежа": "RUB",
            "Кэшбэк": "nan",
            "Категория": "Красота",
            "MCC": 5977.0,
            "Описание": "OOO Balid",
            "Бонусы (включая кэшбэк)": 6,
            "Округление на инвесткопилку": 0,
            "Сумма операции с округлением": 316.0}]```
2. Запустить выполнение программы командой `python -m src.services`.
3. В результате получим транзакции в формате json, отфильтрованные по наличию в описании телефонных номеров.


### Для модуля reports.py:

1. В Python файле `reports.py` необходимо ввести объект `DataFrame` транзакций и дату в формате: `"2020-02-16 12:49:52"`.
   При отсутствии ввода даты пользователем, используется дата на момент вычисления функцией.
2. Запустить выполнение программы командой `python -m src.reports`.
3. В результате получим объект `DataFrame` средних трат в каждый из дней недели за последние три месяца
   (или с даты выбранной пользователем), также выполнится запись отчета в файл `report.json` по умолчанию или 
   указанный пользователем в аргументах декоратора функции.

## Тестирование:

Данный проект покрыт юнит-тестами с использованием фреймворка pytest.
Для их запуска выполните команду `poetry run pytest` из корневой директории проекта.

### Реализованы:

### Для модуля views.py:

+ Тестирование функции, объединяющей функциональность основной страницы приложения с валидными значениями.

### Для модуля utils.py:

+ Тестирование функции, преобразующей файл транзакций из формата xlsx в объект dataframe с валидными значениями.
+ Тестирование функции, преобразующей файл транзакций из формата xlsx в объект dataframe при отсутствии файла транзакций
  по указанному пути.
+ Тестирование функции, возвращающей приветствие пользователю при разном времени суток.
+ Тестирование функции, возвращающей отфильтрованный по дате и статусу список словарей транзакций при валидных
  значениях.
+ Тестирование функции, возвращающей отфильтрованный по дате и статусу список словарей транзакций при отсутствии
  операций в заданном периоде.
+ Тестирование функции, возвращающей отфильтрованный по дате и статусу список словарей транзакций при ошибках в
  программе.
+ Тестирование функции, возвращающей список словарей крайних цифр, сумм расходов и сумм кэшбека по каждой карте при
  валидных значениях.
+ Тестирование функции, возвращающей список словарей крайних цифр, сумм расходов и сумм кэшбека по каждой карте при
  отсутствии транзакций в заданном периоде, неверном пути к файлу и неправильном формате даты.
+ Тестирование функции, возвращающей топ пять транзакций по сумме платежа при валидных значениях.
+ Тестирование функции, возвращающей топ пять транзакций по сумме платежа при единственной транзакции в заданном
  периоде.
+ Тестирование функции, возвращающей топ пять транзакций по сумме платежа при отсутствии транзакции в заданном периоде.
+ Тестирование функции, возвращающей список актуального курса для заданных валют при валидных значениях.
+ Тестирование функции, возвращающей список актуального курса для заданных валют при ошибке запроса на сервер.
+ Тестирование функции, возвращающей список актуального курса для заданных валют при неверном пути к файлу списка валют.
+ Тестирование функции, возвращающей список актуального курса акций S&P500 при валидных значениях.
+ Тестирование функции, возвращающей список актуального курса акций S&P500 при возврате с сервера пустого списка.
+ Тестирование функции, возвращающей список актуального курса акций S&P500 при ошибке запроса на сервер.
+ Тестирование функции, возвращающей список актуального курса акций S&P500 при неверном пути к файлу списка акций.

### Для модуля services.py:

+ Тестирование функции, фильтрующей транзакции по наличию в описании телефонных номеров с валидными значениями.
+ Тестирование функции, фильтрующей транзакции по наличию в описании телефонных номеров с пустым списком транзакций.
+ Тестирование функции, фильтрующей транзакции по наличию в описании телефонных номеров при отсутствии транзакций 
  с номерами.

### Для модуля reports.py:

+ Тестирование функции, возвращающей средние траты в каждый из дней недели за три месяца при валидных значениях.
+ Тестирование функции, возвращающей средние траты в каждый из дней недели за три месяца
  при отсутствии транзакций в заданном периоде.
